## 3. Wave Breakdown & Action Plan

1. **Wave 1 (Shared Foundations)**:
   - Create reusable shared components: `StatCard`, `Timeline`, `ListPageScaffold`, `KeyValueList`, and `ActionDialogLayout`.
   - Enhance `/design-system` with documentation for each newly added piece.
2. **Wave 2 (Master & Settings Modules)**:
   - Refactor `Departments`, `Designations`, `Locations`, `Vendors`, `AssetCategories`, `Users`, `Roles`, and `AuditLogs` into modular `src/components/<module>/` directories with dedicated `.schema.ts`, columns, filters, and React Query hooks.
3. **Wave 3 (Employees, Profile, Auth)**:
   - Extract Employees into dedicated `src/components/employees/` (`AddEditEmployee.tsx`, `Employee.schema.ts`, `EmployeeColumns.tsx`, `EmployeeFilters.ts`, and `src/hooks/queries/employee.ts`).
   - Standardize `Profile.tsx` and auth flow screens (`Login.tsx`, `AuthFlow.tsx`).
4. **Wave 4 (Assets, Software, Portal & Dashboard Polish)**:
   - Integrate newly created Wave 1 shared components (`Timeline`, `StatCard`, `KeyValueList`) across `AssetDetail`, `SoftwareDetail`, `Dashboard`, and Portal screens.
5. **Wave 5 (API Consistency & Guardrails)**:
   - Verify `validateExists`, activity logs, query whitelists, options indexing, and Swagger across all API modules.
   - Enforce guardrails with `check:ui` and `gen:module` validation.
